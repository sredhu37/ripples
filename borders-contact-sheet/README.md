# Contact sheet: every border map

Made by `npm run borders -- sheet` from the border files of [#386](https://github.com/sredhu37/ripples/issues/386) (commit 1f057ad3). For the review in [#394](https://github.com/sredhu37/ripples/issues/394): look at every map, and write each wrong border as a comment there (map year, place, what is wrong).

Beige is land no polity held (drawn neutral). Red dots are pins of that map year. Black squares in the South Asia inset are the ADR 0016 control points; from 1858 all must be inside the India colour (orange).
