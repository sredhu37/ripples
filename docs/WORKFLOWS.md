# Workflows

One row per file in `.github/workflows/`. Generated by `npm run workflows:map` from the YAML; do not edit by hand.
CI fails when this file differs from the generated one. The flow diagram is [factory-flow.svg](factory-flow.svg). Spec: [factory.md](factory.md).

| File | Trigger | What it does | Starts next |
| --- | --- | --- | --- |
| `evidence-cleanup.yml` | `pull_request`: closed | Deletes the merged PR's folder from the evidence branch and squashes the branch. | nothing |
| `factory-build.yml` | `issues`: labeled, closed<br>`workflow_dispatch`: inputs issue, pr, human | Build agent. Picks a factory:ready issue (label swap), builds it, opens or updates the PR; also runs fix rounds. When an issue closes it dispatches the next unblocked one. | `pr-checks.yml` (the PR it pushes) |
| `factory-gate.yml` | `workflow_dispatch`: inputs pr, mode, source<br>`pull_request_review`: submitted<br>`issue_comment`: created | Gate. Risky-file list, gate agent, then squash merge or factory:human. Also relays Sunny's approvals and comments on a PR in Needs human. | `factory-build.yml` (fix round on human comment or change request)<br>`pages.yml` (the squash merge to main) |
| `factory-pr-link.yml` | `pull_request_target`: opened, reopened, ready_for_review | Puts the issue of a hand-opened PR with `Closes #n` in review. | nothing |
| `factory-review.yml` | `workflow_run`: completed; after pr-checks<br>`workflow_dispatch`: inputs pr, plant_fail | Review. Four review agents in parallel on a factory PR once pr-checks is done, suggestions issue, round counter. PASS goes to the gate, FAIL back to build. | `factory-build.yml` (FAIL: fix round, max 5)<br>`factory-gate.yml` (PASS: to the gate) |
| `factory-sweep.yml` | schedule `7 * * * *` (UTC)<br>schedule `0 9 * * 1` (Europe/Berlin)<br>`workflow_dispatch`: inputs task, dry_run | Safety net. Restarts paused factory:ready issues, flags stuck builds, reconciles the board, sends the Monday triage reminder. | `factory-build.yml` (restarts paused ready issues) |
| `factory-sync.yml` | `issues`: labeled, unlabeled, closed, reopened | Keeps board #2 in step with the factory: labels of an issue; closed and reopened issues get their label. | nothing |
| `pages.yml` | `push`: branches main<br>`workflow_dispatch`: inputs simulate_broken | Builds and deploys the site, runs the live check, opens a revert PR when the live site is broken. | `pr-checks.yml` (the revert PR) |
| `pr-checks.yml` | `pull_request` | Every PR check, one job per required check of the main ruleset, plus the workflow map and flow diagram checks. | `factory-review.yml` |
