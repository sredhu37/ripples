# Glossary

Shared vocabulary for this project. Agents use these terms exactly.

| Term | Meaning | Avoid |
| --- | --- | --- |
| Otto | The otter guide who talks in speech bubbles | mascot, bot |
| Lesson | One 5-minute unit: story, toy, 3 questions | module, chapter |
| Toy | The small interactive thing in a lesson (for example a slider) | simulation, game |
| Toy action | A quiz question answered by doing something in the toy | puzzle |
| Badge | Earned when all 3 questions of a lesson are right | trophy, achievement, points |
| Trail | The map screen listing the lessons in order | menu, home |
| Group | A set of lessons on one theme (Money and Work, Business, ...) | course, level |
| Fact card | One screen per lesson: 5 claims, a source for each, what was simplified | review sheet |
| Ripple Town | The made-up town where all lesson stories happen | island |
| Ask Dad | The closing conversation question for the parent | homework |
| In real life card | The Germany and euros example at the end of a lesson | case study |
| Animated beat | A story beat that builds up tap by tap: one Otto line and one new diagram part per tap | slideshow, animation |
| Term | A new word the lesson teaches by name (barter, money, price, save). Written between *stars* in lesson text, shown highlighted | keyword, vocabulary |
| Save code | Parent-only text code that restores name, language and badges | backup, password |
| Ticket size | The average price or coin value of one sale | receipt, basket |
| Market share | The fraction or slice of total customers buying from one business | monopoly |
| Mittelstand | German small and medium enterprises featured in the scale lesson | big business |
